Decky Loader's globals block, pinned verbatim.

WHY THIS FILE EXISTS
--------------------
Decky's loader skips its ENTIRE globals block when `window.SP_REACT` is already
set. So when Tender installs the three globals first and Decky starts after it,
Decky's whole frontend renders through OUR React, OUR ReactDOM and OUR JSX
shape. A deviation here does not break Tender's panel — it breaks DECKY's user
interface, on a machine whose owner installed Decky for other plugins.

That makes "our shape equals Decky's shape" a cross-project invariant with no
diff that shows both halves. This file is the other half, checked out of
upstream and held still; `steamGlobals.ts` beside it is ours, and
`steamGlobals.test.ts` holds the two predicates against each other.

    // deliberate partial import
    const DFLWebpack = await import('@decky/ui/dist/webpack');
    window.SP_REACT = DFLWebpack.findModule((m) => m.Component && m.PureComponent && m.useLayoutEffect);
    window.SP_REACTDOM =
      DFLWebpack.findModule((m) => m.createPortal && m.createRoot) ||
      DFLWebpack.findModule((m) => m.createPortal && m.__DOM_INTERNALS_DO_NOT_USE_OR_WARN_USERS_THEY_CANNOT_UPGRADE);

    console.debug('[Decky:Boot] Setting up JSX internals...');
    const jsxModule = DFLWebpack.findModule((m) => (m.jsx && m.jsxs) || (m.jsx && Object.keys(m).length == 1));
    if (jsxModule.jsxs) {
      window.SP_JSX = jsxModule;
    } else {
      window.SP_JSX = {
        jsx: jsxModule.jsx,
        jsxs: jsxModule.jsx,
        Fragment: window.SP_REACT.Fragment,
      };

  }

THE WAIT ABOVE IT, WHICH IS NOT IN THE MARKERS
----------------------------------------------
Decky waits for Steam's own init before it reaches the block:

    const isSteamAppInitialized = () => {
      const app = window.App as unknown as SteamAppInitialization | undefined;
      return app?.BFinishedInitBeforeLogin?.() ?? app?.BFinishedInitStageOne?.() ?? false;
    };
    while (!isSteamAppInitialized()) {
      await new Promise((r) => setTimeout(r, 0));
    }

It is outside the markers because it is not part of the SHAPE — waiting longer
or shorter cannot hand Decky a different React. It is reproduced here anyway
because skipping it is how a finder silently answers `undefined`: the module
cache is read once, and reading it before Steam has finished registering its
modules means the cache never holds them. `steamGlobals.ts` waits the same way,
with a deadline the loader does not have.
